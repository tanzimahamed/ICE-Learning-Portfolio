---

### 📚 Topics Covered

### 1️⃣ OSI Model Architecture
Explains the 7-layer OSI (Open Systems Interconnection) model, describing how data flows through different layers — from physical 
transmission to application-level communication.
📄 `OSI_Model_Architecture.pptx`

### 2️⃣ ISDN (Integrated Services Digital Network)
Covers the fundamentals of ISDN — a set of communication standards 
for simultaneous digital transmission of voice, video, and data over 
traditional telephone networks.
📄 `ISDN_Lecture_ICE.pptx`
📄 `Telecommunication ISDN + OSI.pdf`

### 3️⃣ SS7 (Signaling System No. 7)
Discusses the SS7 protocol suite used for setting up and managing 
telephone calls in most parts of the public switched telephone 
network (PSTN).
📄 `SS7.pdf`

### 4️⃣ Multiple Access Techniques
Covers methods like TDMA, FDMA, and CDMA that allow multiple users to 
share the same communication channel efficiently.
📄 `Multiple_access.pdf`

### 5️⃣ Multiplexing
Explains techniques used to combine multiple signals into one for 
transmission over a shared medium, improving bandwidth utilization.
📄 `multiplexing-160915144719.pdf`

### 6️⃣ Complete Course Notes
A consolidated set of notes covering the entire Telecommunication 
Networks syllabus for final exam preparation.
📄 `TN Note Final.pdf`
